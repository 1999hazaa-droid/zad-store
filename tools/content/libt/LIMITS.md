# مركز الاختبار النهائي للمكتبة — حدود الاختبار (صراحةً)

## ما الذي يُحسب فعليًا
- **فحص آلي (الخادم):** لكل قسم (23 قسمًا): وجود موارد منشورة، التصنيف، النطاق العمري، الملفات المفحوصة؛ وعامة: تصنيفات الصفوف، مستويات الموارد، حماية بيانات الطفل (سياسات القراءة المفتوحة للزائر على الجداول ذات الأعمدة الشخصية)، التكرار، السلامة (تقريبي)، المشكلات العاجلة، عيّنة الجودة، حالة الروابط.
- **اختبار الأداة (مستورد):** نتائج اختبارات تشغيل حقيقية بمتصفح Chromium وبقاعدة البيانات الحقيقية، مع المصدر والتاريخ. لا تُسجَّل يدويًا.
- **يدوي:** يسجّله المدير بعد تجربته بنفسه مع كتابة ما جرّبه.

## ما لم يُختبر ولا يُعتبر ناجحًا
- متصفحات Firefox وSafari والأجهزة الفعلية: بيئتنا Chromium فقط → «لم يتم الاختبار» حتى يسجّلها المدير.
- سرعة الصفحات على شبكة حقيقية (المقاس المحلي لا يمثلها).
- فتح الملفات والمعاينة والطباعة والتنزيل على أجهزة فعلية؛ حذف المورد مع التأكيد؛ رفع الملفات؛ تعديل التصنيفات؛ معاينة المورد قبل النشر؛ سيناريوهات الطفل الخمسة؛ ربط المورد بنشاط محدد.
- جودة المحتوى التربوية واللغوية: عينة بشرية تُسجَّل من مركز مراجعة المكتبة (قائمة التسعة بنود).
- الملف الخاص (غير العلني) لا يمكن فحصه من الخادم.
- اختبار الأجهزة يعمل على الصفحات بعد تحميلها مع Supabase مُحاكى بردود فارغة: يفحص هيكل الصفحة وليس تخطيط البطاقات المعبّأة (تغطيها اختبارات كل صفحة بمقاسات الهاتف/اللوحي/الحاسوب).
- اختبارات الإدارة بـ SQL تُنفَّذ داخل معاملة تُلغى؛ لم تُنشأ أو تُعدَّل أي بيانات حقيقية.

## قواعد الجاهزية
`لم يبدأ` ← لم يُشغَّل فحص. `تحتاج إلى معالجة` ← اختبار حرج فاشل أو مشكلة حرجة مفتوحة. `لم يكتمل الاختبار` ← اختبارات حرجة لم تُجرَ. `جاهزة مع ملاحظات` ← ملاحظات غير حرجة. `جاهزة` ← لا شيء. الاعتماد النهائي لا يتم إلا في الحالتين الأخيرتين وبصلاحية مراجع تربوي/مدير المكتبة، ويبطل إن ساءت الحالة.
## الإغلاق
لا تُغلق مشكلة إلا بعد «تم الإصلاح» ثم «إعادة اختبار» ناجحة؛ الإعادة الآلية تعيد حساب الاختبار فعلًا.
